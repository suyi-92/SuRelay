# SuRelay 管理说明

安装完成后运行 sr，任意目录均可使用；Alpine 的 ash 也可调用。入口是 /usr/local/bin/sr，实际程序随项目更新。如果该命令已被其他程序占用，安装会停止并提示，不覆盖其他程序。

## 终端面板

`sr` 默认在同一个终端窗口内刷新菜单、输入和结果，退出后恢复原来的终端内容。菜单、表单和确认页使用随内容收缩的居中面板，操作提示紧跟内容，窗口缩放后自动调整位置。方向键或数字选择，Enter 确认；Esc 返回上一级，q 退出。选中项用文字颜色和 `›` 标记区分，不使用底色高亮，关闭颜色后也能辨认。

修改配置时在带边框的输入框内逐项填写，当前值或建议值以灰字预览，输入后替换，直接回车使用；框下标明默认值类型或错误提示。Esc 或 Ctrl+C 取消当前操作，密码和 Token 隐藏显示。节点名称输入后直接保存，值未改变时不重复应用。更新脚本/内核、证书检查续期、启用登录防护直接执行；服务控制选定目标后执行，解除封禁输入 IP 后执行。

输入页显示操作对象、步骤、字段用途和当前值/建议值，不再把上一段命令输出或完整链接堆在表单顶部。添加上游 VLESS 每次只处理一个节点：粘贴链接（1/3）、设置出口名称（2/3）、设置本机入口端口（3/3），核对后保存；不再收集多条链接或要求空行结束。添加下一节点时重新选择添加入口，取消当前节点不会影响已保存的出口。HTTP/SOCKS5 表单区分远端代理地址/端口、认证信息和本机入口端口。端口等带校验的字段输错后可原地重填。出口、公钥、服务、日志和防火墙规则均用列表选择，长条目自动折行；取消选择直接返回。

其余需要核对的变更使用「确认执行／取消」选项，不再手输 YES、VERIFIED、PASSWORD、RESTORE 或出口名称。普通变更默认选中确认，删除、恢复备份、关闭防护及 SSH 登录验证默认选中取消；取消后直接回到菜单；已发生部分变更或回滚时先显示实际结果。SSH 登录验证仍要求在新窗口登录成功后明确选择继续。重装和卸载仍使用下文的独立确认流程。过长的说明可用 PgUp/PgDn 阅读，未展示完整前确认只向下翻页。公钥支持一次粘贴多行；VLESS 输入只接受一条链接，粘贴内容不会自动回答后续字段或确认。操作结果按 Enter 返回，超出一屏时显示行范围，使用方向键或 PgUp/PgDn 翻页。

新增、修改和删除节点、刷新订阅、IPv6、域名、服务控制、安全设置及高级维护统一收起执行日志。执行时只显示简短状态，完成后显示操作结果和必要信息（如节点名称、入口端口、导出文件或备份位置）；按 p 查看详细输出。命令失败不会显示成功，回滚、部分生效和需要手动处理的提示仍会显示。主动选择「查看日志」「查看详细状态」「查看规则与监听」及诊断入口时，保留完整查询结果。安装、重装、卸载和编辑器继续使用各自的交互流程。

节点页列出名称、连接地址、端口和协议；订阅页列出名称和适用客户端，与菜单共用居中面板和相邻的操作提示。**完整链接直接显示在当前面板内**，按面板宽度折行；按 **Enter / c**（也兼容 1）请求复制当前完整原始链接，按 **Esc / 0** 返回。多个节点或订阅格式用 **←→** 切换，不增加二级菜单。窗口容纳不下时显示行范围，用 ↑↓、PgUp/PgDn 或 Home/End 查看；即使只显示其中一段，复制键仍复制完整链接。

复制键使用原始地址，不含边框、显示折行或尾部回车，需要本机终端支持并允许 OSC 52（经 SSH 传递）；面板只能提示请求已发送，无法确认本机是否接收。如果剪贴板没有更新，按 **p** 在当前面板展开原文，再用鼠标选中链接；再次按 p 收起。原文区域使用终端整行宽度连续输出地址，不插入换行、缩进、侧边框或行间光标指令，由终端自然折行。空闲和复制提示更新时不重绘链接；鼠标复制时是否合并自然折行由本机终端决定，过长链接可扩大窗口后选取。居中视图的鼠标选区可能带入边框与折行，请使用复制键或原文视图。其他结果页仍可按 p 查看完整原文。

订阅按**格式**组织，同一格式的客户端共用链接。目前支持 Mihomo / Clash Meta YAML。格式名称和链接由导出模块提供，新增格式需先实现导出和订阅服务支持，再登记到格式列表，面板与安装摘要自动展示，无需为每个客户端增加界面分支。

编辑器、安装、重装和卸载使用各自的原生交互，完成后按 Enter 返回。`sr status`、`sr update` 等直接命令保持逐行输出。不支持全屏或小于 50 列、18 行的终端自动使用普通菜单，也可运行 `sr --plain` 手动切换。

## 更新与兼容

项目与 GitHub 仓库名称为 **SuRelay**，新安装代码目录为 `/opt/SuRelay`，运行数据为 `/etc/surelay`。旧安装执行 README 顶部的更新命令，自动迁移默认代码目录并更新仓库地址；自定义目录原地更新。也可在更新代码后执行 `bash surelay.sh migrate`。

迁移先备份配置与 sr 入口，再将旧代码目录移到新目录，留下旧路径兼容链接。已存在新目录时停止，不覆盖另一份安装。旧部署的运行数据、订阅服务、证书和 SSH 策略继续按原路径识别，不重启服务或轮换身份；新安装使用新的路径与服务名。`RRB_*` 环境变量仍兼容旧自动化。

日常使用 `sr update`：只允许干净 main 分支快进到 origin/main，本地独有提交或修改会阻止更新。面板内选择「更新 SuRelay」时隐藏 Git 和迁移过程日志，完成后选择「重启管理面板」加载新版，或「关闭面板」退出；重启管理面板不重启 VPS 或代理服务。失败时显示错误摘要，按 p 查看详细日志。菜单打开时不联网更新。脚本与内核分开更新；Alpine 内核采用项目校验过的固定版本。

如果首次安装停在 SSH 验证，面板会提示「安装尚未完成」，执行 `sr install` 继续；更新代码和注册 sr 本身不等于部署完成。

IPv6-only VPS 请按 [分阶段流程](install-flow.md) 准备 config.env：填写 IPv6、将 SERVER_IP_IPV4 留空、设置 ENABLE_IPV6_LISTEN=true 与 PROXY_IP_VERSION=ipv6，再执行已有配置的安装流程。

## 节点、出口与域名

日常应用配置先备份，将 `config.env` 中的 `RESET_PROXY_KEYS` 保存为 `false`，再生成候选 JSON、执行 sing-box check，随后应用、验证监听并调整项目防火墙规则。即使旧配置遗留了 `RESET_PROXY_KEYS=true`，添加或修改出口等日常操作也会继续复用现有身份。失败时恢复本地配置并尝试恢复服务，备份位置会显示。操作不轮换 UUID、Reality 密钥或订阅 token。订阅/DNS 发布失败时保留已通过验证的本地配置，在对应菜单重试发布。

旧版面板若提示「请先将 RESET_PROXY_KEYS 设为 false」，退出面板，在 VPS 上编辑 `/opt/SuRelay/config.env`，将该项改为 `RESET_PROXY_KEYS="false"`，保存后重新运行 `sr` 再添加出口。自定义安装使用实际代码目录中的 `config.env`；无需删除密钥或重装。

出口支持 HTTP、SOCKS5 和现有的 TCP VLESS/Reality。新增或删除出口前，已自动分配的名称与端口会写成固定值。更改入口端口或节点名称会改变相应的客户端条目；客户端需要更新订阅。

「检查出口连通性」只检测服务器直连及各转发出口：通过临时的本机 SOCKS 入口和所选出站访问 HTTPS 检测站点，逐项显示目标、成功/失败、出口 IP 和请求耗时。代理认证也参与检测；某一项失败会继续其余项目。临时配置仅 root 可读，完成、超时或 Ctrl+C 取消后清理测试进程；不重启现有服务。结果不等于客户端到 VPS 的公网入口可达。

「服务与诊断 → 检查配置与监听」只检查节点参数、sing-box 配置、代理/订阅服务及本机监听，不再混入 SSH、fail2ban 和防火墙的整套安装验证。安全策略在「VPS 安全」查看；原有安装验证命令仍保留。结果中的通过/失败使用文字和颜色区分，长结果可翻页。

IPv6 在手动选择启用后才探测。关闭 IPv6 要求已有 IPv4，关闭本项目 IPv6 节点和监听，保留系统 IPv6。CF 清理仅处理地址与注释均匹配旧项目配置的记录；不能确认归属的记录会保留并提示。

停用域名模式切回 IP 节点与 HTTP 51040 订阅，客户端需更新订阅地址。证书及 Nginx 本机站点保留供复用，不删除其他站点。更换域名或申请证书涉及外部 DNS 与证书状态，失败时可能需要在 CF 控制台检查已完成的变更。

## VPS 安全

- 自定义端口规则支持 TCP、UDP、端口范围、来源 IP/网段及 IPv4/IPv6；IPv6 规则要求 UFW 已启用 IPv6 支持。菜单只修改带 SuRelay 自定义标记的自建规则。
- SSH/代理/订阅的必要规则由对应设置维护，其他软件规则只展示。本机 UFW 放行不等于云安全组放行，也不等于该端口已监听。
- 仅服务器安全防护模式下，自定义端口和 SSH 端口迁移无需代理出口文件；未启用的代理与订阅端口可供其他服务使用，配置及当前会话的 SSH TCP 端口仍受保护。
- SSH 端口迁移先保留旧端口并启用新端口，支持 systemd SSH socket 模式。在新终端通过新端口验证公钥登录，选择「已验证登录成功，继续」后才撤下旧端口。取消或失败会恢复备份；云安全组和 NAT 映射需先准备好。
- 公钥显示指纹；替换先添加新公钥，验证后才移除旧公钥。始终保留至少一把有效公钥。删除后同步清除安装配置中的旧公钥来源，避免重跑安装重新添加。
- 关闭密码认证需要再次验证公钥登录。临时开启密码认证不设置密码、不解锁账号；重跑完整安装的最终加固阶段会重新关闭密码认证。
- fail2ban 设置仅作用于 sshd jail；停用不关闭其他 jail。白名单、封禁参数和端口写入专用配置。

SSH 变更保留当前终端并另开窗口验证；自定义 AuthorizedKeysFile、Match 内 Include 等复杂配置会提示手工处理。备份位于 /root/surelay-backups/surelay-*，包含敏感信息，权限仅 root 可读。

## 备份与恢复

“备份节点配置”保存节点参数、出口文件与身份密钥，恢复前再创建当前状态备份。恢复使用当前服务器的路径，不导入备份中的任意目标路径；SSH、防火墙开关和登录防护设置不随节点恢复覆盖。恢复不同节点身份会使原有订阅或节点失效。

“高级配置”在临时副本中编辑，校验后应用。SSH、路径及身份重置字段需通过专用操作处理。重置重装继续使用原先的预览、备份和 RESET 确认流程。

## 卸载

`sr uninstall` 或主菜单 `8) 卸载 SuRelay` 先展示删除清单，输入 `UNINSTALL` 后备份并核验，再停用节点/订阅、删除项目配置和专用文件，清理项目代理端口规则及当前安装的 sr 入口。不会自动重新安装。

保留 SSH 配置、公钥、账户、系统软件包、自定义业务端口规则、其他站点、Cloudflare DNS、代码目录及历史备份；卸载不恢复成密码登录。重装入口仍为 `bash install.sh --reset`，确认词是 `RESET`。
